## À quoi sert une gemme ?

Une gemme Apotheosis se **sertit dans un objet à affixes** pour lui donner un bonus. Le bonus dépend à la fois :

- du type de gemme ;
- de sa rareté ;
- du type d'objet compatible avec elle.

L'infobulle de la gemme indique les objets dans lesquels elle peut entrer. Une gemme marquée **Unique** ne peut apparaître qu'une seule fois sur le même objet.

## Comment sertir une gemme

1. Vérifie que l'objet possède une **châsse**, aussi appelée *socket* ou emplacement de gemme.
2. Ouvre une **table de forge**.
3. Place l'objet à gauche et la gemme à droite.
4. Vérifie le résultat avant de le prendre.

Le guide et les avancements de la version installée confirment l'utilisation de la table de forge.

## Où trouver des gemmes

Le guide intégré indique qu'elles peuvent apparaître :

- dans des coffres ;
- plus rarement sur des créatures tuées par un véritable joueur ;
- plus fréquemment sur les boss.

Les chances exactes ne sont pas recopiées ici, car elles peuvent être modifiées par le pack.

## Raretés

L'ordre confirmé est :

1. **Commune** — gemme « fissurée » dans la traduction anglaise embarquée ;
2. **Peu commune** — « ébréchée » ;
3. **Rare** — « imparfaite » ;
4. **Épique** ;
5. **Mythique** — « parfaite/flawless » selon l'intitulé du jeu ;
6. **Ancienne** — qualité maximale d'amélioration dans cette version.

## Améliorer une gemme

La **table de taille des gemmes** améliore une gemme. Le guide installé confirme qu'une amélioration demande :

- la gemme à améliorer ;
- une seconde gemme de même rareté ;
- de la poussière de gemme ;
- des matériaux de rareté.

Le coût exact est affiché par l'interface et augmente avec la rareté.

## Obtenir la poussière de gemme

Deux méthodes sont confirmées :

- jeter une gemme dans le monde et faire tomber une enclume dessus ;
- utiliser la **table de recyclage** après l'avoir fabriquée.

La table de recyclage sert aussi à décomposer les objets à affixes en matériaux de rareté.

## Retirer une gemme

Le retrait impose un choix :

- **Fiole d'expulsion brûlante** : conserve l'objet, détruit les gemmes retirées ;
- **Fiole d'extraction arcanique** : récupère les gemmes, détruit l'objet.

Dans les deux cas, le guide intégré indique d'utiliser une table de forge.

!!! danger "Toujours lire le résultat"
    Ne valide pas l'opération avant d'avoir vérifié quel élément sera détruit.

## Les familles présentes dans cette version

Les données de `Apotheosis 6.5.2` contiennent 21 variantes :

- Ballast, Brawler, Breach, Combatant, Guardian, Lightning, Lunar, Samurai, Slipstream, Solar, Splendor, Tyrannical et Warlord ;
- Earth et Royal Family pour l'Overworld ;
- Blood Lord et Incandescent Inferno pour le Nether ;
- Endersurge et Mageslayer pour l'End ;
- Twilight Forest et Frozen Queen pour Twilight Forest.

Le bonus précis de chaque variante change selon l'objet et la rareté. Cette première version du wiki ne simplifie donc pas ces valeurs : lis l'infobulle de la gemme dans ta partie.
