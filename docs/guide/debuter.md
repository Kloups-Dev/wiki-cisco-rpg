# Premiers réflexes

!!! success "Vérifié — mods présents"
    JEI, Jade, FTB Quests, Controlling, Xaero's Minimap et Xaero's World Map figurent dans l'instance analysée.

## Identifier ce que tu regardes

**Jade** peut afficher le nom d'un bloc ou d'une créature visée. Si une mécanique n'est pas claire, commence par relever le nom exact et le mod indiqué dans l'infobulle.

## Trouver une recette

Dans l'inventaire, utilise **JEI** :

- survole un objet et consulte les touches affichées pour voir sa recette ou ses usages ;
- tape `@nomdumod` dans la recherche pour ne voir que les objets d'un mod ;
- tape plusieurs mots pour réduire la liste.

Les touches peuvent avoir été modifiées. Si une commande ne répond pas, ouvre **Options → Contrôles**, puis cherche le nom du mod avec **Controlling**.

## Suivre la progression

**FTB Quests** est installé. Consulte le menu de quêtes du pack avant d'utiliser une commande ou de sauter une étape : certaines récompenses et progressions peuvent être liées aux quêtes.

## Se repérer

Xaero's Minimap et Xaero's World Map sont présents. Les raccourcis exacts dépendent des contrôles de ton client ; vérifie-les dans le menu des touches plutôt que de supposer une touche universelle.
