# Chercher un objet ou une recette

## Dans le wiki

La loupe en haut de page utilise une recherche française. Essaie des mots d'usage plutôt que seulement des noms anglais :

- `gemme`, `sertissage`, `châsse` ;
- `coffre`, `rangement`, `stockage` ;
- `biome`, `structure`, `village` ;
- `quête`, `compétence`, `progression`.

L'index des mods contient aussi le **nom exact de chaque fichier `.jar`**. Une recherche sur une partie du nom, par exemple `aether`, `ars` ou `storage`, retrouve donc le mod même si sa fiche détaillée n'existe pas encore.

## Dans Minecraft avec JEI

!!! success "Vérifié — `jei-1.19.2-forge-11.8.1.1034.jar`"
    JEI est bien installé dans cette version du pack.

- `@apotheosis` limite les résultats aux objets d'Apotheosis.
- `@toms_storage` limite les résultats à Tom's Simple Storage.
- `@waystones` limite les résultats à Waystones.

Pour une recette exacte, **JEI en jeu reste la référence**, car le pack contient KubeJS et CraftTweaker : ils peuvent changer une recette par rapport à la page publique d'un mod.

## Si tu ne connais pas le mod

Survole l'objet. L'infobulle indique généralement son mod. Si ce n'est pas visible, active les infobulles avancées avec `F3 + H`, puis cherche l'identifiant ou le nom obtenu dans le wiki.
